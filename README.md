**STRKERZONE Boxing Club**

we are a boxing club in Dubai. this website contains 5 pages 
that allow viewers to witness the different parts of the website 

**WEBSITE PAGES**

Home - the introduction of the club
About Us - the page that demonstrates who we are a boxing club 
Age Groups - this page shows the different age groups we accomadate for 
Competitons - this shows the requiremetns needed in order to compete ata high level for our club
Contact - this page allows viewers to contact us and apply for a trial. 

**STRUCTURE OF FILE**

index.html - Home 
about.html - About Us
age groups.html - Age Groups
competitions.html - Competitons
contact.html - Contact Us
style.css - Style of the website 
script.js - Navigation

**HOW TO OPEN THE WEBSITE**

- dowload the github lab from github
- open the folder called STRYKERZONE 
- tap on the file called index.html
